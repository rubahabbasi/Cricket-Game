# Cricket-Game 🏏

An interactive, browser-based Cricket Game built with pure JavaScript, HTML5, and CSS3.

## ✨ Features
- Real-time score tracking and overs counter
- Interactive batting and bowling controls
- Dynamic gameplay logic and match results
- Clean, responsive UI for mobile and desktop

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
